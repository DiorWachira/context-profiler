Signature components and motion

  1. Token ruler. Major/minor ticks re-step (5 → 2,000 tok) as you zoom, so the scale is always readable.
  2. Icicle stack. Request → kind → segment → part. Width is tokens, heat is influence; scroll zooms at the cursor, W A S D for keys.
  3. M1 · M2 · Δ markers. Drop two markers on the ruler; the readout sums tokens, influence and cost between them.
  4. Ablation raster. 32 masks as a waterfall of kept and removed cells; pick a mask to read the response it produced.
  5. Sweep. On load a single trace line crosses the stack and heat develops behind it: attribution is computed, not decorated. 1.2 s, once.
  6. Reduced motion. Sweep, heat develop, bar glide and button lift all switch off; every state is still reachable by keyboard.
