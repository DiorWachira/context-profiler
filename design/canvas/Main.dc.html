How a run works

offline, budget-capped, every call cached by (model, params, masked-request hash)
  1. S1Importctxprof import traces.jsonl

    JSONL or OTel GenAI spans, mapped in one module.

  2. S2Segmentsegmenter.yaml

    Headings, tool schemas, chunks and turns get stable fingerprints.

  3. S3Ablate × 32ctxprof profile --n 32

    Each segment kept with p = 0.5, temperature 0.

  4. S4FitLasso(α=cv)

    Mask → score. Weights are attributions; fit checked on held-out masks.

  5. S5Aggregatectxprof aggregate

    DEAD, CRITICAL and VOLATILE across traces.

  6. S6Prunectxprof prune > prompt.diff

    A unified diff, never a silent edit.

  7. S7Verifyctxprof verify --threshold 0.95

    Recommends only if held-out agreement clears the bar.

ctxprof 0.4.0 · scoring: logprob (local) + black-box (embedding similarity) Demo data: the deliberately bloated JobBridge support agent. Influence is a surrogate estimate, not ground truth.
